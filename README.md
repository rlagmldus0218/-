# 2023 산업연관표 분석 웹앱

한국은행 「2023년 산업연관표(연장표)」 투입산출표(생산자가격)의 **통합대분류(33)·통합중분류(83)·통합소분류(165)·기본부문(380)** 4개 분류를 브라우저에서 탐색하고 산업연관분석을 수행하는 웹앱입니다. 서버 없이 GitHub Pages에서 동작합니다.

## 사용법
화면 위쪽의 **책갈피 탭**(산업 정보 · 원자료 탐색 · 구조 분석 · 시뮬레이터 · 단위·출처)을 눌러 주제를 바꿔 봅니다. 탭은 주소 뒤 `#simulation`처럼 기억되어 링크로 공유할 수 있습니다.
1. 배포 주소에 접속해 **"자료 불러오기"** 버튼을 누릅니다.
2. **부문 찾기와 산업 정보**: 산업명·코드를 입력하면 입력창 아래에 후보 목록(콤보박스)이 뜹니다(↑↓·Enter 사용 가능). 4개 분류에서 동시에 검색하며, 하나를 고르면 **구조 지표**(총산출·부가가치율·수출률·수입률·유발계수·영향력/감응도계수)와 **취업·고용 지표**(취업자수, 취업·고용계수, 취업·고용유발계수 2020~2023)가 표시됩니다.
3. **원자료 탐색**: 분류 → 시트(12종) → 행 검색/선택 → 열 검색 순으로 값을 확인합니다. 선택한 행의 단위가 표 위에 표시됩니다.
4. **구조 분석**: 분류를 고르고 "분석 실행"을 누르면 영향력계수·감응도계수 상위 15개 부문과 핵심 부문 목록이 나옵니다.
5. **시뮬레이터**: 분류를 고르고 산업 검색창(콤보박스)에서 산업을 선택한 뒤 최종수요 증가액(백만원)을 입력해 시나리오에 추가하고 "파급효과 계산"을 누릅니다. 결과는 CSV로 내려받을 수 있습니다.

## 단위
| 항목 | 단위 |
|---|---|
| 거래표, 최종수요 항목별 유발액, 시뮬레이션 결과 | **백만원** (2023년 당해년 가격, 생산자가격). 1,000백만원 = 10억원 |
| 투입계수, 유발계수, 영향력·감응도계수 | 무차원 비율 (영향력·감응도는 평균=1인 지수) |
| 취업자수, 임금근로자수 | 천명 (전업환산) |
| 취업계수, 고용계수 | 명 / 총산출 10억원 |
| 취업유발계수, 고용유발계수 | 명 / 최종수요 10억원 |
| 조원 단위 연장표 시트(총산출·부가가치 등) | 조원 (앱에서는 투입산출표 기준 백만원으로 표시) |
| 구성비 | % |

## 분석 방법
- 국산 투입계수 `Ad`로 생산유발계수 `L = (I − Ad)⁻¹` (원표 시트와 일치함을 `validation-report.json`에서 확인)
- **생산유발액** `x = L · Δf` (Δf: 국내 생산물 최종수요 증가액 벡터)
- **부가가치유발액** `= 부가가치율(총투입계수표 9690행) × x`
- **수입유발액** `= Am · x` (수입투입계수 `Am` 기준 중간재 수입. 최종수요로 직접 수입되는 완제품은 제외)
- **영향력계수** `= (L의 열합) ÷ (열합의 평균)`, **감응도계수** `= (L의 행합) ÷ (행합의 평균)`
- **취업·고용유발**: 한국은행 연장표(통합대분류 33부문)의 2023년 **공식 취업·고용유발계수**(명/최종수요 10억원)에 최종수요 증가액(10억원 단위)을 곱해 추정합니다. 중·소·기본부문을 고르면 그 부문이 속한 대분류의 계수를 적용하므로 세부 부문의 실제 값과는 다를 수 있습니다. (대분류 취업계수와 생산유발액을 직접 곱해 재계산하면 공식 유발계수와 취업 최대 약 4%, 고용 최대 약 17% 차이가 나서 공식 계수를 쓰도록 했습니다.)
- 분류가 클수록 계산이 가볍고, 기본부문(380)은 가장 세밀합니다. 부문 통합 정도에 따라 결과가 달라질 수 있으므로 같은 시나리오를 여러 분류에서 비교해 보세요.
- 한계: 선형 모형(가격·공급제약·기술변화 무시), 연장표는 2020년 실측표 기준 추계, 음(−)의 수요 감소는 지원하지 않습니다.

## 파일 구성
- `index.html`, `style.css`, `app.js` : 웹앱
- `data/` : 변환된 자료(`meta.json`, `summary.json`(연장표 취업·고용 등 17개 시트), 분류별 시트 12개) — `model.py`가 생성
- `model.py` : 엑셀 → JSON 변환과 검증 (`raw/` 폴더에 투입산출표 4개, 상품분류, 연장표 엑셀을 넣고 실행)
- `validation-report.json` : 검증 결과

## 자료 출처와 이용 조건
- **출처**: 한국은행 경제통계시스템(ECOS) 「2023년 산업연관표(연장표)」(투입산출표 생산자가격 4개 분류, 취업·고용 통계). 작성기관과 저작권자는 **한국은행**입니다.
- **이용 조건**(한국은행 ECOS 「통계정보이용지침」): 한국은행이 작성한 통계정보는 **출처를 명시하는 한 상업적 용도를 포함해 무료로 자유롭게 사용·가공·재배포**할 수 있습니다. 이용자는 통계를 임의로 변경·왜곡하지 않고, ECOS(한국은행)에서 제공된 정보임을 명확히 적어야 합니다. 「저작권보호방침」은 정보를 수정·변경·가공한 경우 그 사실도 분명히 밝히도록 합니다.
- **이 웹앱의 준수 사항**
  - 화면(단위·출처 탭, 하단 문구)과 이 문서에 출처를 표기합니다.
  - **가공 사실**: ① 엑셀을 `model.py`로 웹용 JSON으로 변환하면서 값을 유효숫자 6자리로 반올림했습니다. ② 영향력·감응도계수, 시뮬레이션 유발액·유발 인원, 산업 정보의 비율 지표(부가가치율·수출률 등)는 이 앱이 계산한 값으로 한국은행 공식 발표 수치가 아닙니다. 그 외 원자료 값은 바꾸지 않았습니다.
  - **개인정보**: 산업 단위로 집계된 통계라 개인정보가 없습니다. (이메일·전화번호·주민등록번호 형태 문자열 검사로 확인)
- **권장 출처 표기**: `출처: ECOS(한국은행), 「2023년 산업연관표(연장표)」, 본 웹앱에서 가공·계산`
- **확인일과 유의**: 이용 조건은 2026.11.18.에 한국은행 ECOS 통계정보이용지침과 저작권보호방침으로 확인했습니다. 지침은 바뀔 수 있으니 재배포·발표 전에 최신 내용을 확인하세요.
  - ECOS: https://ecos.bok.or.kr/
  - 저작권보호방침: https://www.bok.or.kr/portal/main/contents.do?menuNo=200228
- 타 기관이 작성한 통계(예: 통계청 자료)를 이 저장소에 추가할 때는 해당 기관의 이용 조건(상업적 이용 제한 등)을 따로 확인해야 합니다.
- 원본 엑셀(`raw/`)은 이 저장소에 올리지 않아도 앱이 동작합니다.
