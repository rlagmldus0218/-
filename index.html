1. 부문 찾기 (4개 분류 통합 검색)

산업 이름이나 코드를 입력하면 4개 분류에서 해당 부문과 상위 분류(기본부문의 경우)를 보여줍니다.

분류코드부문명상위 분류 (소 › 중 › 대)

2. 원자료 탐색

분류와 시트(12종)를 고르고 행을 선택하면 각 열과의 값을 볼 수 있습니다.

자료를 불러온 후 표시됩니다.
열 코드열 이름값

3. 산업 구조 분석 (영향력·감응도계수)

생산유발계수표(레온티에프 역행렬)로 계산합니다. 영향력계수 = 해당 부문 열합 ÷ 전체 열합 평균(다른 산업을 끌어올리는 힘), 감응도계수 = 행합 ÷ 전체 행합 평균(다른 산업 수요에 반응하는 정도). 둘 다 1보다 크면 핵심 부문입니다.

영향력계수 상위 15 (무차원 지수, 평균=1)

감응도계수 상위 15 (무차원 지수, 평균=1)

4. 최종수요 증가 시뮬레이션

국내 생산물에 대한 최종수요(소비·투자·수출) 증가액을 입력하면 생산·수입·부가가치 유발액을 계산합니다. 여러 산업은 합산됩니다.

1,000백만원 = 10억원. 양(+)의 수요 증가만 지원합니다.
